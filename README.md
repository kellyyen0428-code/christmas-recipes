# 聖誕夜食譜

寫給料理新手的聖誕節食譜網站，共十道菜（前菜、主菜、甜點、飲品）。
純 HTML + CSS + 少量 JavaScript，直接用瀏覽器打開 `index.html` 就能看。

## 特色

- 聖誕夜主題：夜空、飄雪、燈串與自繪 SVG 插圖。
- 每篇食譜都能「一步一步做」：下一步／上一步、燈串進度、內建計時器。
- 食材清單可以點選打勾，確認都備齊了再開始。

## 這個專案怎麼運作

所有規則都寫在 [CLAUDE.md](CLAUDE.md)：風格、資料夾結構、每篇食譜的固定格式，以及新增食譜的流程。
請 AI 新增內容時，只要給它一個食譜網址，它會依照手冊完成：

1. 讀取來源並用自己的話重寫成固定格式。
2. 複製 `recipes/_template.html` 建立新頁面。
3. 在首頁對應分類加上卡片。

互動功能由 `assets/recipe.js` 自動套用，新增食譜不需要寫任何程式。

## 資料夾

- `index.html`：首頁，依前菜、主菜、甜點、飲品分區。
- `recipes/`：每道菜一個 HTML 檔；`_template.html` 是範本。
- `assets/style.css`：全站唯一樣式表。
- `assets/recipe.js`：食譜頁的互動功能。
- `assets/images/`：SVG 插圖。

## 內容來源

食譜內容參考公開食譜後重新撰寫，每一頁底部都附有原始來源連結。插圖為本專案自行繪製。
